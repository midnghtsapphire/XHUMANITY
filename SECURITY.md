# Security Policy

## Scope

This repository currently contains strategic and operational documentation for climate program deployment.

## Reporting a Vulnerability

If you discover a security issue (including data exposure, integrity risks, or supply-chain concerns), report privately to the repository owner through GitHub security reporting channels.

## Security Baselines

- Do not commit secrets, credentials, or API keys.
- Use least-privilege access for all deployment tooling.
- Require audit logs for emissions data modifications.
- Preserve immutable reporting records for verification.
